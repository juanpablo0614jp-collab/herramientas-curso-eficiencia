# Herramientas del curso «Caracterización de energía y eficiencia energética»

Páginas web estáticas del curso (UNAL, grupo EM&D). Cada herramienta es un solo archivo HTML; no hay compilación ni servidor.

| Archivo | Herramienta |
|---|---|
| `index.html` | Portada con enlaces a las cuatro herramientas |
| `calculadora-linea-base.html` | Línea base energética con la Res. UPME 016 de 2024 y seguimiento con CUSUM |
| `priorizacion.html` | Matriz de priorización de medidas (marco teórico 05) |
| `simulador-solar.html` | Simulador solar y batería (marco teórico 06) |
| `autoevaluacion.html` | Autoevaluación de los marcos teóricos 02, 04, 05 y 06 |

Todo se calcula en el navegador. Este repositorio no contiene datos de los casos AMI del curso.

Publicación: Vercel, importando este repositorio sin cambiar la configuración (Framework: Other).
